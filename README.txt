■ 公開前に必要な作業
1. assets/aquaculture.jpg（山梨県の陸上養殖施設の写真）を追加してください。
   キャンバス上に直接貼り付けられた画像のため、書き出しに含められませんでした。
2. ［受付時間］［担当者名］、募集要項の［ ］部分を埋めてください。
3. 「お問い合わせフォーム」「エントリーフォーム」のボタンはリンク先が未設定です。
4. 創立日・許可番号は現行の登記・許可証と照合してください。

フォントはGoogle Fonts（Noto Sans JP / Inter）をインターネット経由で読み込みます。
